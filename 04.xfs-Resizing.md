## XFS Filesystem Resizing:

XFS is a high-performance 64-bit journaling filesystem used as the default filesystem in Red Hat Enterprise Linux, Rocky Linux, and CentOS which was originally designed at Silicon Graphics, Inc. XFS is the default file system for Red Hat Enterprise Linux 7. A critical operational constraint is that XFS supports online growing but does NOT support shrinking.

**XFS can only grow, never shrink directly.**  
It only supports **growing/extending**. Therefore, if you want to move space from `/home` to `/`, you must use a **backup → recreate → restore** approach.


### XFS Filesystem Comparison:

| Filesystem | Grow             | Shrink          |
| ---------- | ---------------- | --------------- |
| XFS        | ✅ Online         | ❌ Not Supported |
| Ext4       | ✅ Online/Offline | ✅ Offline       |
| Btrfs      | ✅ Online         | ✅ Online        |



### Example Scenario:

The steps in this guide demonstrate the following space reallocation:
- `/home` = 12G
- `/` = 12G
- Reduce `/home` by 5G
- Add that 5G to `/`

## Step-3: Remove or Reduce/Shrink and Recreate LV


### Method-1: Remove and Recreate LV: (Recommended)

This is the recommended, safest method. The logical volume is completely removed, recreated at the new smaller size, formatted, and the backup is restored.


### Unmount `/home`:

_Check which processes are using `/home` :_
```
lsof /dev/mapper/rl-home
```


_Kill Active Processes:_
```
kill -9 <pid>
```


_Unmount:_
```
umount /dev/rl/home
```
